# Project Report
## NLP-Based Student Feedback Sentiment Analysis and Classification System

### Abstract
This project uses Natural Language Processing and Machine Learning to analyze student feedback and classify it as Positive, Neutral, or Negative.

### Problem Statement
Manual analysis of large amounts of student feedback is time-consuming. This system automates sentiment classification.

### Objectives
1. Apply NLP to student feedback.
2. Clean and preprocess text.
3. Extract TF-IDF features.
4. Train a sentiment classifier.
5. Provide a simple web interface.

### Methodology
Collect feedback → Clean text → TF-IDF → Logistic Regression → Prediction → Dashboard.

### Software Requirements
Python 3.9+, Streamlit, Pandas, Scikit-learn, Joblib.

### Hardware Requirements
Basic laptop/desktop with 4 GB RAM or more recommended.

### Conclusion
The project demonstrates a practical application of NLP and Machine Learning for educational feedback analysis.
