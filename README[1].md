# 🎓 NLP-Based Student Feedback Sentiment Analyzer

A simple NLP + Machine Learning project that classifies student feedback as **Positive, Neutral, or Negative**.

## Features
- NLP text preprocessing
- TF-IDF feature extraction
- Logistic Regression classifier
- Single feedback analysis
- Batch CSV analysis
- Sentiment chart
- Download analyzed CSV
- Streamlit web interface

## Project Flow
Student Feedback → Preprocessing → TF-IDF → Logistic Regression → Sentiment → Dashboard

## Installation
```bash
git clone https://github.com/YOUR_USERNAME/Student-Feedback-Sentiment-Analyzer.git
cd Student-Feedback-Sentiment-Analyzer
pip install -r requirements.txt
python train_model.py
streamlit run app.py
```

## Example
Input: `The teaching method is excellent and easy to understand.`

Output: **Positive 😊**
